# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any LDTTeam project, please **do not** open a public GitHub issue. Publicly disclosing a vulnerability before it is fixed puts other users at risk.

Instead, please report it privately using GitHub's built-in vulnerability reporting:

1. Go to the **Security** tab of the relevant repository.
2. Click **Report a vulnerability**.
3. Fill in the details and submit.

We will review your report and respond as soon as possible. Once the vulnerability is resolved, we will coordinate with you on disclosure timing if appropriate.
